## 🤖 项目

- **[RoboCup 2026 轮式格斗机器人](https://github.com/tian11111/robocup-2026-wheeled-combat)**  
  面向 RoboCup 武术擂台的实车控制程序，包含传感器、安全控制、状态机策略、视觉接口和现场标定工具。

- **[轮式格斗机器人仿真器](https://github.com/tian11111/wheeled-combat-simulator)**  
  基于 `.NET 8 + Godot 4 .NET + Python` 的桌面仿真平台，支持确定性仿真、比赛回放、控制器接入和真机遥测标定。

- **[Pocket TTL Monitor](https://github.com/tian11111/pocket-ttl-monitor)**  
  基于 `STM32F405 + LVGL` 的便携式串口 / TTL 监视与调试工具。

- **[Omnibot F4 全向物流小车](https://github.com/tian11111/omnibot-f4)**  
  基于 STM32F407 的麦克纳姆轮物流机器人，包含 PID 速度闭环、OpenMV 视觉、蓝牙遥控和夹爪机构控制。
